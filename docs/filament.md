# Zeus Matrix Choice

Matrix Choice is a multiple choice grid component form for filamentPHP

## Features

- 🔥 use as a radio button
- 🔥 use as a checkbox button
- 🔥 set Column Data and Row Data
- 🔥 ask me for more
