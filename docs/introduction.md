## Introduction
@zeus Matrix Choice is a multiple choice grid component form for filamentPHP.

**[Demo](https://demo.larazeus.com/admin/components-demo/matrix) · [Github](https://github.com/lara-zeus/matrix-choice) · [Discord](https://discord.com/channels/883083792112300104/1282759292411314199)**

## features

- 🔥 use as a radio button
- 🔥 use as a checkbox button
- 🔥 set Column Data and Row Data
- 🔥 ask me for more
